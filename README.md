# Hyper Island (Android)

Dynamic Island als Overlay – Kotlin + Jetpack Compose.

## Bauen
- Android Studio: Ordner öffnen, Run drücken (Handy per USB, Android 8+)
- Oder auf GitHub hochladen: Actions baut die APK (Artifact "HyperIsland-debug-apk")

## Einrichten
1. App öffnen, "Über anderen Apps anzeigen" und "Benachrichtigungszugriff" erlauben
2. "Starten" drücken
3. Xiaomi/HyperOS: Autostart erlauben und Akku auf "Keine Einschränkungen" stellen

## Bedienung
Tippen = auf/zu, lang drücken = Details, wischen = schließen
